# r57 native gameplay buttons

- Direct buttonpoll mappings installed in PollControls after PollKeyboardButtons().
- Z=fire, A=use, B=swap weapon, C-left/right=strafe, C-up=swap, C-down=drop.
- D-up/down=look, D-right=autorun toggle, L=map, R=180 turn.
- Start is not handled here; it remains platform SDL Escape.
